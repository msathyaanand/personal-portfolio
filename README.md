# Personal Landing Page

This is a simple, clean, and responsive personal landing page. It's designed to be a central hub for all your online profiles and contact information, similar to a "link-in-bio" page.

**Live Demo:** [https://msathyaanand.github.io/personal-portfolio/](https://msathyaanand.github.io/personal-portfolio/)

## About The Project

This project provides a straightforward HTML and CSS template for creating a personal landing page. It's perfect for professionals, freelancers, and anyone looking to create a simple and elegant online presence. The page is designed to be easily customizable.

## Features

*   **Responsive Design:** Looks great on mobile devices and desktops.
*   **Social Media Links:** Easily link to your LinkedIn, Twitter, and other social media profiles.
*   **Contact Information:** Includes icons for phone and email.
*   **Customizable:** Easy to change the colors, fonts, and content to match your personal brand.
*   **No Frameworks:** Built with plain HTML and CSS, so it's lightweight and easy to understand.

## Technologies Used

*   HTML5
*   CSS3
*   [Font Awesome](https://fontawesome.com/) for icons
*   [Google Fonts](https://fonts.google.com/) for custom fonts

## How to Use

To use this template for your own landing page, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/msathyaanand/personal-portfolio.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd personal-portfolio
    ```
3.  **Customize the content:**
    *   Open `index.html` in a text editor.
    *   Replace the profile picture `download.jpg` with your own photo.
    *   Change the name, title, and bio to your own information.
    *   Update the links to your social media profiles and contact information.
4.  **View the page:**
    *   Open the `index.html` file in your web browser to see your customized landing page.

## Customization

You can customize the look and feel of the page by editing the `<style>` section in the `index.html` file.

*   **Colors:** Change the background gradient, button colors, and text colors to match your personal brand.
*   **Fonts:** The template uses the "Patrick Hand" font from Google Fonts. You can choose a different font from [Google Fonts](https://fonts.google.com/) and update the link in the `<head>` section of the `index.html` file.
